# Dataset 2: Glaucoma & Diabetic Retinopathy Fundus Image Dataset

## Overview
Dataset 2 contains clinically annotated optical fundus image scans focusing on Diabetic Retinopathy vascular signs and Glaucoma optic disc/cup ratio (CDR) metrics.

### Specifications:
- **Primary Conditions**: Glaucoma, Diabetic Retinopathy (Diabetes)
- **Image Format**: High-resolution Fundus Scans (.png, .jpg)
- **Resolution**: Normalized to 640x640 input tensor grid
- **Usage**: Multi-class classification training and validation for Model 2 and Model 3.
