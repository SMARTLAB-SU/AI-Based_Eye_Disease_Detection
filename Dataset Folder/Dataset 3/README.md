# Dataset 3: General Eye Pathology & Normal Control Dataset

## Overview
Dataset 3 comprises control fundus photographs along with retinal vascular biomarker scans used for Dementia screening and normal control baseline establishment.

### Specifications:
- **Primary Conditions**: Dementia (Retinal Microvascular Signs), Normal Baseline Control
- **Image Format**: Calibrated Fundus Images (.jpg, .png)
- **Target Resolution**: 640x640 tensor input format
- **Usage**: Multi-pathology evaluation and custom FNet/Perceiver cross-attention model validation.
