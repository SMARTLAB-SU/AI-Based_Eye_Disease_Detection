# Dataset 1: Ocular Disease Intelligent Recognition (AMD & Cataract)

## Overview
Dataset 1 contains high-resolution color fundus photographs categorized for Age-Related Macular Degeneration (AMD) and Cataract screening.

### Specifications:
- **Primary Conditions**: AMD (Age-Related Macular Degeneration), Cataract
- **Image Format**: RGB Fundus Photography (.jpg, .png)
- **Resolution**: 640x640 preprocessed standardized resolution
- **Usage**: Used for training Model 1 (EfficientNetV2-S) and Model 2 (Swin Transformer) feature extractors.
