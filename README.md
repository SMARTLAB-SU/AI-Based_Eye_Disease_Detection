## 📊 Dataset Folder

The dataset repository is structured into three primary sub-datasets for multi-disease classification:

* **Dataset 1**: Ocular Disease Intelligent Recognition dataset focused on Age-Related Macular Degeneration (AMD) and Cataract screening.
* **Dataset 2**: Retinal Fundus image dataset with annotations for Glaucoma (Optic Cup-to-Disc Ratio) and Diabetic Retinopathy (Diabetes).
* **Dataset 3**: Control baseline fundus imagery and vascular biomarker scans for Dementia and healthy controls.

## 🧠 Model (Architectures, Weight Files & Notebooks)

The system incorporates three core model configurations:

| Model Category | Architecture | Description | Weight File | Code (Notebook) |
| :--- | :--- | :--- | :--- | :--- |
| **Model 1** | **EfficientNetV2-S** | Fast, parameter-efficient convolutional neural network for rapid screening | `efficientnetv2s_scratch_best.pth` | `Model1_EfficientNetV2.ipynb` |
| **Model 2** | **Swin Transformer** | Hierarchical Vision Transformer with shifted windows for feature context | `swin_scratch_best.pth` | `Model2_SwinTransformer.ipynb` |
| **Model 3** | **FNet / Perceiver / ResNeXt** | Custom Fourier mixing & Cross-Attention models for low-compute edge deployment | `fnet`, `perceiver`, `resnext50` weights | `Model3_FNet_Perceiver_ResNeXt.ipynb` |

### Diagnostic Target Classes (6 Categories):
1. **AMD** — Age-Related Macular Degeneration
2. **Cataract** — Lens Opacification
3. **Dementia** — Retinal Microvascular Biomarkers
4. **Diabetes** — Diabetic Retinopathy Vascular Signs
5. **Glaucoma** — Optic Nerve Head & RNFL Loss
6. **Normal** — Healthy Retinal Baseline

## 💻 App (.exe, .iss, .py)

The `App/` directory contains all components required to run, build, and package the application:

* **`.py`**: Core Python modules including:
  * `App/main.py`: Entry point for launching the clinical GUI interface.
  * `App/ui/`: Responsive PyQt GUI windows, dynamic scaling, and custom styling.
  * `App/models/`: PyTorch neural network loader, custom FNet/Perceiver definitions, and prediction engine.
  * `App/utils/`: Fundus camera video capture, preprocessing pipelines, PDF/text report generator, and patient save manager.
* **`.iss`**: `setup.iss` Inno Setup script for building the standalone Windows installer executable (`VisionAI_Setup_v1.0.exe`).
* **`.exe`**: Executable build output specifications and packaging instructions via PyInstaller.

## 🚀 Quick Start Guide

### 1. Clone the Repository
```bash
git clone https://github.com/SMARTLAB-SU/AI-Based_Eye_Disease_Detection.git
cd AI-Based_Eye_Disease_Detection
```

### 2. Install Dependencies
```bash
pip install -r App/requirements.txt
```

### 3. Run Application
```bash
python App/main.py
```
*(Or launch directly from root via `python main.py`)*

---

## 🔨 Building Desktop Installer (.exe)

1. Run PyInstaller to build the bundled binary directory:
   ```cmd
   pyinstaller App/build.spec
   ```
2. Open `App/setup.iss` in **Inno Setup** and click **Compile** to generate `VisionAI_Setup_v1.0.exe`.
